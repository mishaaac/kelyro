# Kelyro v0.1.0-alpha.1

`v0.1.0-alpha.1` is the first Kelyro pre-release and closes I-01 Foundation.
It establishes the local-first, cross-platform base for I-02 Student & Learning
Core without adding educational domain behavior.

## Highlights

- Cross-platform CLI and Foundation TUI for Linux, macOS, and Windows.
- Safe workspace initialization, discovery, ownership, and artifact integrity.
- Layered configuration and native credential-store abstractions.
- Workspace-local SQLite state, migrations, sessions, audit, and diagnostics.
- Atomic backup/restore and portable export/import with conflict protection.
- Deny-by-default network privacy and explicit, version-aware update checks.
- Reproducible archives for `amd64` and `arm64` with `SHA256SUMS`.

## Compatibility and security

- The release requires Go 1.24 or newer when building from source.
- Kelyro works offline by default and does not send telemetry or student content.
- Secrets are excluded from workspaces, backups, exports, logs, and command
  output; native credential availability remains operating-system dependent.
- Workspace-owned paths reject traversal and unsafe symlink targets.

## Known limitations

- Student and learning-domain features begin in I-02 and are not included.
- Update checks report releases, but Kelyro does not download or install them.
- Checksums detect corruption but are not cryptographic publisher signatures.
- Linux native secret storage requires `secret-tool` and an active Secret
  Service session; headless environments use explicit environment references.

## Verification

The release is gated by unit tests, Foundation lifecycle E2E tests, `go vet`,
the race detector, Linux/macOS/Windows builds and smoke tests, cross-compilation,
offline behavior, backup/restore, export/import, and secret-redaction checks.
