# Kelyro v0.2.0-alpha.3

`v0.2.0-alpha.3` is a compatibility prerelease that fixes a TUI session
coordination regression found during a complete manual acceptance pass over
the published `v0.2.0-alpha.2` feature set.

## Fixed

- Re-entering the already completed learner Setup screen now always schedules
  the dashboard refresh it marks as active.
- The session checkpoint remains serialized behind that refresh, and graceful
  quit can no longer wait indefinitely for a dashboard command that was never
  started.
- A model regression and a real-process Foundation E2E cover completed Setup
  re-entry, return to Home, deferred checkpoint completion, and clean exit.

## Verification

- Complete `go run ./tools/quality all`, including unit/integration tests,
  Foundation/Student/Research E2E, `go vet`, Linux race coverage, CLI build,
  version smoke, and help smoke.
- Fresh uncached unit tests, tagged E2E, and TUI race tests.
- Manual production-binary acceptance from a new workspace, including full
  onboarding and diagnostic, every TUI area, Student Core CLI lifecycles,
  backup/restore, Markdown regeneration, full export/import, maintenance, and
  offline privacy behavior.
- Live Brave query-to-bundle dogfooding produced a durable
  `ready_with_caveats` Source Bundle with complete provenance; all three
  opt-in public Research smokes passed.
- CGO-disabled builds succeeded for Linux, macOS, and Windows on amd64 and
  arm64. The release workflow must repeat its native three-platform quality
  matrix and packaged Linux smoke before publication.

## Security and privacy

- No secret storage, network permission, source trust, fetch boundary, or
  retained-content policy changed.
- Live Research remains deny-by-default and requires provider configuration,
  a credential in Foundation Secrets, and `privacy.allow_network=true`.

## Known limitations

- Brave remains the only production SearchProvider.
- Mutable public content can legitimately produce no Claim or Source Bundle;
  fresh workspaces without reviewed Registry ownership normally report
  qualified support as `ready_with_caveats`.
- No production Curriculum Compiler, Learning Pack generation, AI runtime,
  plugin platform, crawler, browser renderer, or background research daemon is
  included.
- `kelyro update check` reports releases but does not install them.
- `SHA256SUMS` detects corruption but is not a cryptographic publisher
  signature.

## Compatibility

- No intentional breaking CLI, configuration, persistence, or workspace
  change was introduced since `v0.2.0-alpha.2`.
- No migration or dependency changed; existing I-01/I-02/I-03 workspaces stay
  compatible.
