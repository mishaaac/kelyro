# Kelyro v0.1.0-alpha.3

`v0.1.0-alpha.3` is the I-02 Student & Learning Core prerelease candidate. It
adds durable, local-first learner state and deterministic educational policies
on top of the I-01 Foundation.

## Added

- Persistent learner profile, learning-goal lifecycle, resumable onboarding,
  mastery thresholds, and a deterministic optional diagnostic.
- Versioned curriculum consumption, prerequisite graph, learner curriculum
  instances, evidence-based mastery, progression, and derived-state repair.
- Persistent mistake memory, study sessions, history, intentional active time,
  retention, spaced reviews, contextual warm-ups, non-punitive streaks,
  achievements, and explainable analytics.
- Deterministic adaptive daily planning and a coherent Student Core dashboard
  exposed through the CLI, height-aware TUI, and protected Markdown export.
- Backup/restore and portable export/import coverage for Student Core state,
  offline/privacy verification, integrity hardening, and deterministic scale
  fixtures.

## Fixed

- Long TUI views are height-bounded and scrollable without affecting input
  screens or persisted learning state.
- Learner-authored input is redacted from diagnostic surfaces.
- SQLite timestamp encoding preserves chronological TEXT ordering across
  platforms while retaining compatibility with prior RFC3339 values.

## Verification

- Full unit, Foundation/Student Core E2E, vet, race, build, and CLI smoke gates.
- Hosted CI on Ubuntu, macOS, and Windows.
- Cross-platform release archives for Linux, macOS, and Windows on `amd64` and
  `arm64`, with reproducible metadata and checksums generated by the protected
  release workflow.

## Known limitations

- Curriculum content is deterministic fixture content, not a researched
  production Learning Pack; Research Engine and Curriculum Compiler are not
  implemented yet.
- The full Exercise/Assessment Engine and generated exercises are not included.
- AI runtime/providers and plugins are not included, and core learning remains
  offline by default.
- `kelyro update check` reports releases but does not install them.
- `SHA256SUMS` detects corruption but is not a cryptographic publisher
  signature.
