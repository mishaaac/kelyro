# Kelyro v0.1.0-alpha.2

`v0.1.0-alpha.2` is a focused post-I-01 Foundation pre-release containing the
development-build update-check fix. It does not add I-02 functionality.

## Fixed

- Fixed `kelyro update check` for local builds using `dev` or `unknown` version metadata.
- Development builds are classified explicitly instead of being parsed as SemVer.
- Release SemVer validation remains strict.
- Development update checks do not access cache, the privacy gate, or the release provider.

## Verification

- The full Go test suite passes.
- `go vet ./...` passes.
- Development and SemVer release smoke tests pass.

## Known limitations

- Update checks report releases, but Kelyro does not download or install them.
- Checksums detect corruption but are not cryptographic publisher signatures.
