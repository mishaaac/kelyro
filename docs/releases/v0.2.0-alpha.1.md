# Kelyro v0.2.0-alpha.1

`v0.2.0-alpha.1` is the I-03 Research & Source Intelligence prerelease. It
adds a provider-neutral, local-first research and evidence layer on top of the
published Foundation and Student & Learning Core.

## Added

- A transport-neutral Research domain with persistent requests, runs, sources,
  immutable snapshots, bounded evidence, structured claims, provenance,
  citations, source bundles, and reproducible research-audit checkpoints.
- Topic-aware authority profiles, Trusted Source Registry, Trust Policy v1,
  Primary Sources First, resource-quality scoring, source diversity,
  multi-source verification, and explicit conflict resolution.
- Privacy-gated discovery, fetch, and release ports; a hardened HTTP client;
  bounded HTML, Markdown, JSON, and text normalization; conditional fetch; and
  a workspace-local offline Research cache.
- Freshness and reverification scheduling, release/deprecation intelligence,
  historical and version-bound guidance, update scanning, evidence drift, and
  impact analysis.
- Explicit handling for standards, package references, playgrounds, community
  resources, video supplements, and commit-addressed source-code evidence.
- Research cost and concurrency controls, trigger policies, content-retention
  and security hardening, plus Research/Sources CLI commands and transparent
  TUI views.
- Provider-neutral contracts for a future source-driven Curriculum Compiler
  and student-safe selective curriculum migration. I-04 is not implemented by
  this release.

## Fixed

- Backup restore now reconciles the integrity metadata of visible generated
  Markdown that intentionally remains outside machine-state backups. A
  restored workspace can regenerate its current projection without weakening
  protection for genuine human edits.
- TUI dashboard refreshes now finish before session checkpoints or graceful
  shutdown writes begin. Completing onboarding no longer lets two SQLite write
  transactions race into an intermittent `SQLITE_BUSY` dashboard failure.
- The Linux race gate has an explicit timeout that allows the complete SQLite
  suite to finish without omitting packages or relaxing assertions.

## Security and privacy

- Live Research remains deny-by-default through `privacy.allow_network`.
- Network destinations are validated against SSRF, redirect, DNS rebinding,
  response-size, decompression, retry, rate, and concurrency limits.
- External source content is always untrusted data, never executable
  instructions. Raw public page bodies are bounded and are not stored in
  SQLite or exported by default.
- Claims cannot become verified evidence without source, snapshot, trust,
  provenance, and citation relationships.

## Verification

- Complete unit, Foundation/Student/I-03 E2E, vet, Linux race, build, and CLI
  smoke gates.
- Hosted CI on Ubuntu, macOS, and Windows, including Linux race coverage.
- Controlled live opt-in checks through the production privacy, HTTP, fetch,
  trust, normalization, and snapshot boundaries.
- Real-source dogfooding across stable concepts, versioned API behavior,
  releases, experimental and deprecated features, security guidance,
  historical behavior, and community-heavy topics.
- Manual acceptance of the packaged Linux `amd64` binary, including TUI,
  offline/allowed-without-provider behavior, reproducible audit metadata,
  Student Core isolation, portable export/import, checksums, and final Doctor
  health.

## Known limitations

- No public search provider is configured. `kelyro research topic` creates an
  explainable, persistent query plan but cannot perform public discovery until
  a separately implemented provider adapter is configured.
- No production Curriculum Compiler, production Learning Packs, or automatic
  curriculum migration is included.
- The full Exercise/Assessment Engine, AI Research Reviewer, AI runtime, and
  plugins are not included.
- `kelyro update check` reports releases but does not install them.
- `SHA256SUMS` detects corruption but is not a cryptographic publisher
  signature.

## Compatibility

- No intentional breaking CLI, workspace, or published migration change was
