# Backend Go Reference Learning Pack

`reference-packs/backend-go-reference.zip` is Kelyro's first I-04 development
Learning Pack. It is a deterministic `learning-pack/v1` archive generated by
`internal/infra/referencepack` through the production
`curriculum-compiler-v1` pipeline and copyright-aware pack builder.

## Status and evidence boundary

The pack is `preview`, contains nine atomic concepts, and deliberately does not
claim to be a production-complete Backend Go curriculum. Its frozen evidence
is a deterministic development fixture using the
`optional_for_fixture` source policy and an explicit caveat. Production use
must replace it with verified I-03 Source Bundles and Claims.

The concept count follows the available fixture evidence. It is not a minimum,
maximum, target, or future curriculum size policy.

## Compiler coverage

The reference source exercises:

- a professional goal with explain, build, debug, operate, and maintain
  outcomes;
- four competency areas and five competencies;
- nine independently atomic concepts;
- an explicit foundational root and an evidence-backed prerequisite DAG;
- vocabulary introduction before use;
- all eight general coverage dimensions;
- a zero-assumption learner baseline;
- current guidance plus one contextual legacy concept;
- beginner traversal with a deferred Go toolchain requirement;
- a portable cross-platform Environment Pack;
- reproducibility metadata and a source-body-free evidence report.

It defines structured pedagogical contracts only. It includes no lesson prose,
exercise runtime, assessment runtime, project runner, AI dependency, network
fetching, or Student Core mutation.

## Reproducibility

Regenerate the committed archive from the repository root:

```bash
go run ./internal/infra/referencepack/cmd reference-packs/backend-go-reference.zip
```

The package test recompiles the source, compares the exact archive bytes with
the committed artifact, and validates the artifact with the production pack
loader. Canonical ZIP timestamps and sorted entries keep output byte-stable.

The Environment Pack points users to `https://go.dev/doc/install`. The
development minimum version is fixture metadata that exercises environment
diagnostics; it is not an automatic installer or a claim about the newest Go
release.
